# 🔐 Autenticador do GitHub em Python

Projeto desenvolvido para estudar autenticação e consumo de APIs utilizando Python.

O sistema realiza autenticação no GitHub através de token de acesso pessoal (Personal Access Token), permitindo validar credenciais e acessar informações da conta autenticada de forma segura.

---

## 🚀 Funcionalidades

- ✅ Autenticação com GitHub usando Token de Acesso
- ✅ Validação de credenciais
- ✅ Consumo da API do GitHub
- ✅ Requisições HTTP com Python
- ✅ Tratamento de erros de autenticação

---

## 🛠 Tecnologias utilizadas

- Python 3
- Biblioteca `requests`
- GitHub REST API
- Autenticação via Token (Bearer)

---

## 📌 Objetivo do projeto

Aplicar na prática conceitos de:
- Autenticação e segurança básica
- Integração com APIs REST
- Manipulação de requisições HTTP
- Tratamento de erros
- Organização de código Python
